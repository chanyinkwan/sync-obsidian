### What happened

未驗證 Amazon 工作有冇 transferable value，就先撤走 ownership
### Why it happened

-> I dont like it, I cant find the value of this task -> bare minimum
### Impact

- 投入時間閱讀文件，但冇形成可用嘅 business picture。
- 未及早辨識 $6M target，因此無法按重要性排列 data gaps。
- Amazon ownership transition 被延遲，需要程哥另行做約 24 分鐘 alignment。
- iPricing、traffic、delivery 等問題停留喺零散 issues，未能連到 revenue impact。
### What's Wrong and How to fix
bare minimum definition = 用最少行動，維持目標喺可接受軌道；唔係用最少努力完成交辦事項

new insight:
bare minimum should be = bare minimum result = goal is 6M, we aim for reached 6m = AE
minimal vital ownership = lazy people goals = good = use the least effort to achieve bare minimum goal
### Right Solution

Frame up the environment for business related projects, so it runs smoothly 
1. **Target**：要達成乜、幾時達成？
2. **Actual**：目前做到幾多？
3. **Gap**：距離目標幾遠？
4. **Levers**：你可以影響邊幾個變數？
5. **Triggers**：數據去到咩水平先需要行動？

For general purposes:
1. **Outcome**：到幾時，必須有咩結果／狀態？
2. **Evidence**：我用咩證據知道目前狀態？
3. **Gap**：目前狀態同目標差幾遠？有咩未知？
4. **Levers**：我可以影響邊幾項？其餘由邊個控制？
5. **Trigger**：咩情況下我要介入、追問或 escalate？
