# Technique - Pitch & Explainer

## Purpose
Synthesize the run's result into a pitch for a named audience.

## When to run / skip
Skip for personal-track runs with no external audience.

## Protocol
1. Ask who the audience is and what decision is sought — one question.
2. Draft the pitch in SCQA format (Situation, Complication, Question, Answer), built only from content already in the run note — introduce nothing new.
3. Present the draft to the user.
4. Revise one question at a time until the user is satisfied.

## Output → run note
`## Pitch` — the SCQA-format draft.
