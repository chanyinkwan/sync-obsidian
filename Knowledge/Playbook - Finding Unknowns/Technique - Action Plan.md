# Technique - Action Plan

## Purpose
Build the risk-first rollout plan that closes out Stage 1.

## When to run / skip
Never skip — this is Stage 1's exit-gate artifact.

## Protocol
1. Pull the known unknowns from the 4 Unknowns Matrix and order the plan's steps so the highest-risk unknowns are attacked earliest.
2. For each step, capture an owner, a verification method, and any dependency.
3. Check every ledger lesson injected for this technique against the drafted steps. Each one must be visibly addressed by a step, or explicitly waived with a stated reason.
4. Run one final review question with the user before closing the plan.

## Output → run note
`## Action Plan` — a numbered list in risk-first order, each step carrying owner / verification / dependency.
