# Pre-flight Checklist

**Budget: 15 minutes, run right before the interview.**

- [ ] Partner told the exact do-not-enter window (start time to end time)
- [ ] Phone silenced
- [ ] Interview link tested (opens, correct meeting)
- [ ] Mic tested
- [ ] Camera tested
- [ ] Water on desk
- [ ] All prep materials closed (brief, story bank, question banks)
- [ ] Tracker note open
- [ ] Room claimed (door shut or signal up)
- [ ] Say the 60-second STAR+Link structure out loud once, as warm-up
