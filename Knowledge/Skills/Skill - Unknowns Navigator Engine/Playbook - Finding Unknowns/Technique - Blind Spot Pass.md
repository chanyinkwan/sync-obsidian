# Technique - Blind Spot Pass

## Purpose
Convert unknown unknowns and unknown knowns into known unknowns before planning starts. This is the only technique that generates a list on the user's behalf — recognition is cheap, generation is what gets outsourced.

## When to run / skip
Never skip.

## Protocol
1. Ask the user to fill or point to `## Brief (the Map)` — one message.
2. Generate 8–12 candidate blind spots across six standard axes: people & approvals, physical & logistics, technical & compatibility, time & sequencing, external & regulatory, assumptions-inside-the-brief. Weight any injected ledger lessons first among the candidates.
3. Present the candidates as ONE numbered recognition list. This is the only sanctioned list-dump in the whole playbook — do not generate any other free-standing list elsewhere.
4. Ask the user which items resonate (mark them).
5. For each marked item, ask one clarifying question at a time. Rewrite the item as a known unknown with a named owner before moving to the next marked item.
6. Sort every known known, known unknown, unknown known, and unknown unknown surfaced so far into the 4 Unknowns Matrix.

## Output → run note
`## 4 Unknowns Matrix` — populate all four quadrants of the table from step 6. Append a short "Top risks" shortlist directly below the table, listing the highest-priority known unknowns from this pass.
