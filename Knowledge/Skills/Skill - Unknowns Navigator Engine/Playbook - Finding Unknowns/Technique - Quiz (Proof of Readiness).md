# Technique - Quiz (Proof of Readiness)

## Purpose
Prove the user can defend the work before walking into the room.

## When to run / skip
Skip if no live audience event follows.

## Protocol
1. Generate 5–8 questions from the run note's own content: edge cases, numbers, stakeholder positions, plan weak points.
2. Ask one question at a time.
3. Grade each answer against what the run note actually says.
4. After all questions are graded, issue a readiness verdict.
5. For every missed question, add an entry to the 4 Unknowns Matrix or flag it as a ledger candidate.

## Output → run note
`## Quiz Results` — each question with its grade, followed by the readiness verdict.
