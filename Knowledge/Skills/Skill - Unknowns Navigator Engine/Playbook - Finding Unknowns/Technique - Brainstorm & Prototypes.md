# Technique - Brainstorm & Prototypes

## Purpose
Generate 2–4 solution directions before committing to one.

## When to run / skip
Skip when the engagement has a mandated approach (for example, a dictated format with no room to choose).

## Protocol
1. Draft a compact comparison table with 2–4 directions: direction / sketch / cost / main risk / which unknown it bets on.
2. Present the table to the user.
3. Discuss one question at a time until the user picks a direction or hybridizes two.
4. Log every rejected direction with its reason in a kill log.
5. Mark the chosen direction clearly.

## Output → run note
`## Brainstorm Directions` — the comparison table, the chosen direction marked, and the kill log of rejected directions with reasons.
