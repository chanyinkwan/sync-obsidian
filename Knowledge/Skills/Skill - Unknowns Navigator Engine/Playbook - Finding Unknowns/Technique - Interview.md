# Technique - Interview

## Purpose
Extract tacit assumptions — unknown knowns — that the Brief and Blind Spot Pass didn't surface.

## When to run / skip
Skip only if the run note's 4 Unknowns Matrix already has 3 or more surfaced assumptions (Unknown Knowns) from a previous session.

## Protocol
1. Check the skip condition; if it holds, offer to skip and stop here.
2. Ask up to 7 questions, strictly one per message, drawn only from: success criteria, hard constraints, stakeholder map, deadline reality, definition of done, biggest private worry, "what would you check first if this failed?"
3. After each answer, reflect it back in 2 lines or fewer.
4. Log the question and answer as one entry in `## Interview Log` before asking the next question.
5. If an answer surfaces an assumption, add it to the 4 Unknowns Matrix.
6. Stop after 7 questions, or sooner if the user has nothing left to add.

## Output → run note
`## Interview Log` — one Q/A pair per exchange, each reflected in 2 lines or fewer. Any assumption surfaced along the way also goes into `## 4 Unknowns Matrix`.
