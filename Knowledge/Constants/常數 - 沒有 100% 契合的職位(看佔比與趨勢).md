# 常數 - 沒有 100% 契合的職位(看佔比與趨勢)

> **論點(一句話):** 任何職位都必然含有你不喜歡的任務(來自不成熟的系統與環境),所以評估一份工作的問題永遠不是「有沒有我不喜歡的部分」,而是「**不喜歡的部分佔比多少、趨勢是否在縮小**」。

## 論點展開

- 「找到 100% 喜歡的工作」是一個**濾鏡**,不是一個存在的目標。濾鏡越厚,越容易把正常的環境噪音誤判為「我選錯了」。
- 不喜歡的任務多數不是職位本身的屬性,而是**系統成熟度**的副產品(unmatured system / working environment)——這意味著它是可以被改變的變數,不是常數。
- 由此推出兩個可操作的量表:
  1. **佔比**:不喜歡的任務佔每週時間多少 %?(時間分配紀錄可直接回答)
  2. **趨勢**:這個佔比在縮小(我在把 admin 變成系統/自動化)還是固定不動(環境不給改變空間)?
- 佔比高但趨勢向下 = 值得留;佔比高且趨勢死平 = 才是真正的離開訊號。

## 觸發場景(什麼時候取用)

- 又開始想「這份工作是不是不適合我」的時候 → 先量佔比與趨勢,再下判斷。
- 評估**下一份**機會(JD、面試反問環節)時 → 問的不是「這職位完美嗎」,而是「不喜歡的部分是什麼、佔多少、我有沒有權限改它」。
- 每月反思(Monthly Reflection)時 → 用時間分配數據實測本月佔比,寫下趨勢方向。

## Self-catch

發現自己在用「有趣 / 無聊」給整份工作打單一分數 → 停,拆成佔比 + 趨勢兩個數字再說話。
