1. **安全性（Security） (1:13-2:56)：** 將一個原本對外公開、具備漏洞的電子商務平台，重構成具備隔離資源、專用 VPC、負載平衡器與 AWS WAF 防護的企業級安全架構。
2. **可靠性（Reliability） (2:56-4:56)：** 針對缺乏容錯能力的醫療應用程式進行優化，導入自動擴展（Auto Scaling）、多可用區（Multi-AZ）資料庫、Route 53 健康檢查與故障轉移機制，實現自我修復。
3. **卓越營運（Operational Excellence） (4:56-6:12)：** 建立自動化營運系統，透過 AWS Chatbot 將警報傳送至 Slack，並允許開發人員直接在聊天介面中執行指令進行快速修復。
4. **效能效率（Performance Efficiency） (6:12-6:58)：** 構建一個全無伺服器（Serverless）的咖啡店庫存管理系統，利用 DynamoDB、Lambda 與 API Gateway 等服務，實現隨需擴展與按量計費的架構。
5. **成本優化（Cost Optimization） (6:58-8:05)：** 設計一套自動化成本治理系統，透過 CloudWatch 與 Trusted Advisor 監測浪費，並利用 AWS SSM 自動化執行清理任務，同時設定 S3 生命週期策略以節省開支。
