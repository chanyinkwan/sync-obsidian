# SA 13 - Fire Drill Interruption Reps

母任務:[[SA Presales Transition]]
Source: [[how to become a Solution Architect or Presales Consultant]] — 行動9：高壓抗干擾演練（消防演習 The Fire Drill）

## Deliverable (what "done" looks like)
成功標準：被干擾後，能在 **15 秒內**優雅地安撫客戶，並精準回到原本的演說主線上，沒有出現手忙腳亂的窘態。Not done until all 3 reps hit this bar.

## Capacity slot
Overlay W8.

## Sub-steps
- [ ] Set 3 random countdown alarms on a phone timer (e.g. 2m14s, 4m50s, 7m10s).
- [ ] Begin the technical presentation.
- [ ] On each alarm, imagine a hostile off-topic question from the interviewer (e.g. "But does this architecture protect against DDoS?").

## Rep counter
Reps = the 3 instances (Mon/Wed/Fri of W8); completion is tracked per instance in TaskNotes. Each instance: random alarms fire → park the hostile question in 15s → return to the exact sentence you were interrupted on.
