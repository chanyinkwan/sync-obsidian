# SA 05 - Three-Tier Discovery Question Bank

母任務:[[SA Presales Transition]]
Source: [[how to become a Solution Architect or Presales Consultant]] — 行動4：建立「三層次痛點」需求挖掘問題庫 (Three-Tier Discovery Question Bank)

Depends on SA 02 (定位宣言 gate must be closed first — the domain choice determines the questions).

## Deliverable (what "done" looks like)
成功標準：完成一份包含 **21 個高質量問題**的「精準診斷題庫」（技術 7 題 / 業務 7 題 / 財務 7 題），且每個問題後面都備註了「這個問題想挖出的核心痛點是什麼」。

## Capacity slot
Overlay W2.

## Sub-steps
- [ ] Open a new document for the selected domain (from SA 02).
- [ ] Write 7 open-ended technical questions ("如何…", "什麼原因導致…", "假如…會怎麼樣" — no yes/no questions), each annotated with the pain it digs for.
- [ ] Write 7 open-ended business questions, each annotated with the pain it digs for.
- [ ] Write 7 open-ended finance questions, each annotated with the pain it digs for.
- [ ] Confirm all 21 questions are open-ended and annotated.
