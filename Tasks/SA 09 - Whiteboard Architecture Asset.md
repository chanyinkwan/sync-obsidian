# SA 09 - Whiteboard Architecture Asset

母任務:[[SA Presales Transition]]
Source: [[how to become a Solution Architect or Presales Consultant]] — 行動8：打造可隨手畫出的「白板架構」資產 (Whiteboard Asset)

This is deliberately light — W6 is the SAA exam / recovery week.

## Deliverable (what "done" looks like)
成功標準：在 **8 分鐘內**憑記憶畫出一幅乾淨、無邏輯錯誤、且面試官一眼就能看懂的系統架構圖，且過程中你的嘴巴沒有停止解釋。Not done until reps below are hit.

## Capacity slot
Overlay W6 (light week — SAA exam recovery).

## Sub-steps
- [ ] Open a blank canvas on a digital whiteboard (Excalidraw / Miro).
- [ ] Pick one typical reference architecture (e.g. standard 3-Tier Web architecture or Data Lake ingestion architecture).
- [ ] Turn off all reference material, set a countdown timer.

## Rep counter
Reps = the 3 instances (Mon/Wed/Fri of W6 — deliberately light, exam recovery week); completion is tracked per instance in TaskNotes. Start at a 10-min countdown, tighten to 8 min by the final instance — draw from memory while narrating, no gaps in narration.
