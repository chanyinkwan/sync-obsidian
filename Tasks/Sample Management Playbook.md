how to 核銷 (write-off via 禮品庫)
1. 喺禮品庫個 website 嗰度申請一部 sample。
2. 個 sample 到咗，或者禮品庫嗰邊嘅 admin 將個 serial number send 咗俾程哥之後，佢就會自己進行掛賬嘅動作。
3. 佢掛完賬之後，就可以喺 sample management website 入面見到嗰個 serial number。
4. 簽完單之後，就可以拎去核銷。
5. 核銷經特殊渠道核銷，原因填「入網測試」或「客戶測試」。
