# BF 價格規劃：集群和交替促銷計劃 (2026-09-18)

**首要行動：** 問 Dehua「H153-381 和 H173-383 從客戶角度來看是同一產品嗎？」它們的 promo (169.99) 和 大促 (149.99) 價格相同，所以這一對是最大的重疊風險。

**數據缺口：** 產品包文件夾只有 11 個型號中 5 個的規格 (H153、B320、B636、B530、B535)。H165、H173、E6888、E5783-230b、E5785-320b 和 E5586-326 的文件夾為空或缺失 (H173 的文件夾標記為 材料不显示；唯一的 E5785 文件是無法打開的 .rar)。這六個產品僅按型號系列和價格分組，標記為 ⚠。

## 各集群的策略

1. **H153 和 H173：嚴格交替。** 不要在同一半月內將兩者都設定為 169.99。給 H153 黑色星期五檔期，因為 249.99 → 149.99 顯示 40% 的折扣力度。給 H173 聖誕節檔期，因為其 大促 利潤率更高 (34.0% vs 30.5%)。
2. **H165 和 E6888：獨立推廣。** H165 可以加入每一個 大促，因為它仍然獲得 45.7%。E6888 最多保持在 promo 深度，因為它在 大促 時獲得 22.5%。
3. **B530 和 B535：交替。B636 作為錨點保持在 run rate**，這符合 Dehua 的規則。
   - 價格倒掛：B535 在 promo (75.99) 比 B530 在 run rate (79.99) 便宜，所以 B530 在這幾週基本賣不動。
   - 修正：B530 採用正常的 promo 檔期。B535 只採用 大促，在那裡它的 4G 大促 利潤率最好 (42.2%)。
4. **E5783 和 E5785：永遠不要同時推廣兩者。**
   - E5783 在每個價格級別都獲得約 9 個百分點的額外利潤，所以它是要保留的產品。
   - E5785 採用 大促 檔期以清空庫存，然後停用，這與會議內容一致。
   - 對於 E5785 UK，在 promo 價格 (69.99) 處停止，因為 大促 利潤率只有 20.0%。
5. **B320 和 E5586：沒有 大促 價格。** 將它們限制在 promo 價格，它們仍然獲得 14.9% 到 22.6%。
   - 大促 利潤率約為 10%，B320 UK 為 9.36%。
   - 大促 價格只比 promo 低 2 到 7，卻要犧牲高達 13 個百分點的利潤率，換來的額外銷量很少。

## 約束條件

1. 同一集群中的產品在同一檔期內不可同價 (H153 和 H173 同為 169.99 就是現有的例子)。
2. 在 promo 的產品的價格不得低於其在 run rate 的較次級同伴 (B535 以 75.99 對比 B530 以 79.99)。
3. 销毛 低於約 20% 的產品不設 大促 價格：B320、B320 UK、E5586 和 E5785 UK。這個下限是我的建議，會議上沒有訂明。
4. 根據 Dehua 的規定，B636 不參與推廣。
5. 任何低於指南的價格都需要 清华哥 的批准。

**預期成果：** 相同的 大促 頭條價格，promo 中沒有重疊產品，並且沒有以約 10% 利潤率銷售的檔期。
