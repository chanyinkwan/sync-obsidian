# North Star — Role Reality & Exit Strategy

> **核心一句：** 呢份工唔係梯（no promotion, no comp growth, limited client access）——係**礦**。每一個鐘的價值 = 挖到幾多可以帶走嘅嘢。目標：**2027 年 4 月（Selina 離開）之前離開，最好 2026 年內搞掂 offer。**

關聯：[[Career Hub Goal]] · [[Exploring What I want to do]] · [[SA Lock-In — Gap Audit & 30-Day Sprint]] · Hub：[[Life @Huawei System]]

**用法：** 做任何 prioritization / 接唔接 task / 點樣分配時間嘅決定之前，返嚟呢度過一次 decision test（§5）。唔係日記，係 decision anchor。有變就寫入 §7 Amendment Log。

## 3. The Four Extraction Streams（挖乜）

| # | Stream | 內容 | 帶去邊 |
|---|---|---|---|
| 1 | **Industry View Pipeline** | 學識由 data → framework → rehearsal 產出「行業視角」輸出。範本：7/15 FWA deck + 答辯（[[15-7-2026 FWA Business Strategies Meeting Transcript]]）、IoT 競爭與市場洞察月報格式。實踐：每週一段 insight paragraph（claim + data + source + so-what），八週滾成自己嘅 mini 月報。 | SA / Solutions Engineer / Analyst 面試同 portfolio |
| 2 | **Money Flow Map** | 錢喺呢盤生意點流：quotation → 審批 → PO → 出貨 → 入賬；pricing 邏輯、margin 結構、rebate、budget cycle、佣金/激勵。每接觸一個環節就記低。 | Deal Desk Manager 彈藥 |
| 3 | **Practice Observation Log** | 記錄呢間世界級規模公司啲人**實際點做嘢**：meeting craft、escalation 路徑、account governance、匯報文化、點樣同 advisor（Dominique 級數）互動。寫成 atomic notes。 | 任何 enterprise 環境嘅 operating maturity |
| 4 | **Communication Reps** | SCQA 私人練習 loop：會前寫 canvas → 會中交付 → 會後對 transcript 自評（plan vs reality）。低風險 rep 場：office 打招呼 task。 | 帶得走嘅 presence + 面試表現 |

**Extraction 紅線（compliance）：** 帶走嘅係 *skills、frameworks、sanitized insight* — 唔係公司機密文件/數據。3D website 只用公開資料。呢條線保護埋將來嘅 reference。

## 5. Decision Tests（每個決定過一次）

1. **Leverage Test：** 呢件事會唔會令我喺公司外更有競爭力（skill / asset / story）？唔會 → 80 分收手或者婉拒。
2. **Cover Test：** 內部工作有冇 double 用途（完成 mandate + 餵 extraction stream）？揀有 double 用途嗰個做法。
3. **Confidentiality Test：** 呢個行動會唔會暴露我知道唔應該知嘅嘢（Ziyi）？會 → 唔做，改用 mandate 做 cover。
4. **Bridge Test：** 呢個行動會唔會燒橋（程哥 / Selina / Ziyi 係將來嘅 reference 同人脈）？會 → 搵另一條路。
5. **Barbell Test：** 呢個鐘應唔應該其實屬於 Track A？（連動 [[Career Hub Goal]] §3 時間配置）
